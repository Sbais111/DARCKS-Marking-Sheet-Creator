    Using the spreadsheet after you download it

    1. Open and enableOpen the file in Excel. It opens on the Data Entry tab. If Excel shows a yellow Protected View bar, click Enable Editing so the formulas calculate.
    2. Enter the codesEach row is a student and each column is a question. Type Y for full marks, or one letter per mark lost. Cells turn green for full marks and red if something doesn't add up.
    3. Hand back feedbackEach student's tab (1, 2, 3...) shows their codes, scores and room for comments, ready to print or share.
    4. Read the resultsSummary shows every score, percentage and grade with colour scales and class averages per question. Grads & names counts students at each grade.

    Need to change a question's marks after the test? Edit the Out of row on Data Entry and every tab updates.
